- The processor holds only PROCESSOR_SECRET and connects only to ALLOWED_STORAGE_HOSTS / ALLOWED_CALLBACK_ORIGINS (empty = reject everything); every job URL and returned put URL is checked against them — prevents SSRF from a forged or replayed job.
- Untrusted files are parsed with bounded sizes (spreadsheet/text/image caps, ZIP entry count/ratio/depth, path-traversal and symlink rejection) and external tools run without a shell; originals are never modified, derived data goes to separate keys.
- Tests: `node --test test/*.check.ts` (fixtures are invented TESZT files generated by `test/make_fixtures.py`).
