- The quote page is one view with four steps (customer+documents → pricing → customer-facing offer → send+followup); step/next-action rules live in `src/lib/quotes/quote-steps.ts`, Timothy prompts go through `useAiPanel().openWith` (prefill only, user sends) — one layout for both UIs, no parallel save, pricing, approval, send or chat path.
- New quotes are created only through the invoker RPC `quote_create_for_lead` (lead + kind required, refuses won/lost leads and leads that already have a quote); changes go through `quote_new_version`, parallel solutions through `quote_new_alternative`; current uniqueness is per (lead, alternative) — keeps new quote, version and alternative distinct and prevents unaddressed drafts.
- Sent (locked) quotes render read-only (`fieldset disabled`); the DB lock guard stays the source of truth.
- Unsent quotes are discarded only via `QuoteDiscardActions`: withdraw = existing status update to `withdrawn`; hard delete only through the invoker RPC `quote_discard_unsent` (refuses sent/locked or any document, package or followup, restores the previous current version) — no client-side quote deletes, no file loss.
