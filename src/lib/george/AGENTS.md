- George organisational signals (`org-signals.ts`) are a pure, deterministic classifier over existing records read with the caller's RLS client in `org-signals.server.ts` (owner-only via `is_owner_role`, SELECT only, no admin client, no AI, no writes) — keeps "central brain" output auditable and free to view.
- One item per source record with a deterministic key (`handoff:`, `lead:`, `project_due:`, `quote_unproven:`, `complaint:<page>:<category>`, `signal:`, `notice:`, `import:`); overlapping followups, notifications and `ai_review_signals` merge into that item instead of repeating — prevents duplicate owner work.
- Evidence classes stay separate: record-proven fact, automatic detection (suspicion), staff complaint, owner-classified bug (status awaiting_fix/checking or reporter verdict), AI assumption; AI findings are notes only and never upgrade a complaint to a bug.
- Status (open/verify/closed) is derived only from source rows; there is no new status table. Areas without real data (attendance link, TIG, materials, contract approval, finance, web requests via admin) are listed as NO DATA, never inferred.
