## 3. Adatfolyam (keletkezés → továbbadás)

```text
Gmail szinkron ──> emails / email_threads / email_thread_access / email_attachments
   │                       │ (cég/projekt hozzárendelés)
Weboldal ──> quote_requests      ▼
Import (Excel) ─> companies, contacts, import_review_items, project_candidates
   ▼
Marketing (lead munkafelület, marketing mód) ──átadás──> Sales (leads.assigned_to)
   ▼
Pipeline: new → quote_prep → quote_sent → follow_up → contract   (lead_status_history, activities)
   │   ajánlat: quotes + quote_items      utánkövetés: followups
   ▼
Megnyert: kizárólag sales_mark_won_with_project() ──> projects
   │   trigger projects_link_lead_records: quotes/followups/kapcsolattartó a projekthez kötve
   ▼
PM: projekt adatlap, tasks, meetings, project_notes, project_documents, attendance_*
AI OS: olvas mindenből saját tooljain át; írás csak engedélyezett toolokkal, ai_action_log naplóval
Website Knowledge → Knowledge Graph (kg_nodes/kg_edges) → AI agentek
```
